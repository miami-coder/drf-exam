# AutoRia Clone

## Технічний стек

- **Backend**: Django REST Framework
- **Database**: PostgreSQL / Supabase
- **Cache / Queue broker**: Redis
- **Task Queue**: Celery
- **Containerization**: Docker + Docker Compose
- **Auth**: JWT (djangorestframework-simplejwt)

## Ролі користувачів

| Роль | Опис |
|------|------|
| Buyer | Перегляд оголошень |
| Seller | Створення оголошень (Basic: 1, Premium: необмежено) |
| Manager | Модерація оголошень |
| Admin | Повний доступ |

## Типи акаунтів

| Тип | Ліміт оголошень | Статистика |
|-----|-----------------|------------|
| Basic | 1 активне | Ні |
| Premium | Необмежено | Так |

## Запуск локально

**Запустити контейнери**
```bash
docker compose up --build
```

**Застосувати міграції якщо вони є**
```bash
docker compose exec app python manage.py migrate
```

**Створити суперкористувача при потребі. В бд він є**
```bash
docker compose exec app python manage.py createsuperuser
```

### 📦 Первинне наповнення бази даних (Seed Data)

У проєкті вже є готовий файл `data.json` в апці `cars`, який містить базовий список автомобільних брендів (makes) та їхніх моделей для 
швидкого старту.

Якщо після запуску контейнерів у тебе пусті списки марок/моделей, їх потрібно завантажити в базу даних за допомогою стандартної команди Джанго `loaddata`.

**Команда для наповнення БД через Docker:**

```bash
docker compose exec app python manage.py loaddata apps/cars/data.json
```

## API Endpoints

### Аутентифікація та Управління Користувачами (Users & Auth API)

| Метод | URL | Опис | Доступ (Permissions) |
| :--- | :--- | :--- | :--- |
| **POST** | `/auth/register/` | Реєстрація нового користувача (автоматично створюється як `Seller`) | Публічний (`AllowAny`) |
| **POST** | `/auth/login/` | Вхід у систему (отримання Access та Refresh токенів) | Публічний (`AllowAny`) |
| **POST** | `/auth/token/refresh/` | Оновлення Access токену за допомогою Refresh токену | Публічний (`AllowAny`) |
| **GET** | `/auth/me/` | Отримання даних профілю поточного залогіненого користувача | Авторизований (`IsAuthenticated`) |
| **PUT/PATCH** | `/auth/me/` | Оновлення даних власного профілю (телефон, email тощо) | Авторизований (`IsAuthenticated`) |
| **POST** | `/auth/create-manager/` | Створення нового облікового запису менеджера | Тільки Адмін (`IsAdminUserRole`) |
| **POST** | `/auth/users/<id>/premium/` | Активація Premium-статусу для користувача за його `id` (`pk`) | Тільки Менеджер або Адмін |
| **POST** | `/auth/logout/` | Вихід із системи (додавання Refresh токену в блекліст) | Авторизований (`IsAuthenticated`) |


### Автомобілі, Марки та Моделі (Cars API)

| Метод | URL | Опис | Доступ (Permissions) |
| :--- | :--- | :--- | :--- |
| **GET** | `/cars/` | Отримання списку всіх активних оголошень автомобілів (з фільтрацією/пошуком) | Публічний (`AllowAny`) / Авторизований |
| **POST** | `/cars/` | Створення нового оголошення про продаж автомобіля | Авторизований (`IsAuthenticated`) |
| **GET** | `/cars/<id>/` | Отримання детальної інформації про конкретний автомобіль за його `id` (`pk`) | Публічний (`AllowAny`) |
| **PUT/PATCH** | `/cars/<id>/` | Повне або часткове оновлення оголошення (доступно власнику, менеджеру або адміну) | Авторизований (Власник / Адмін) |
| **DELETE** | `/cars/<id>/` | Видалення оголошення автомобіля з бази даних | Авторизований (Власник / Адмін) |
| **GET** | `/cars/makes/` | Отримання списку всіх доступних марок автомобілів (напр. Audi, BMW, Toyota) | Публічний (`AllowAny`) |
| **GET** | `/cars/makes/<make_id>/models/` | Отримання списку моделей для конкретної марки (напр. для Audi -> A4, A6, Q7) | Публічний (`AllowAny`) |

### Курси Валют та Ціноутворення (Pricing API)

| Метод | URL | Опис | Доступ (Permissions) |
| :--- | :--- | :--- | :--- |
| **GET** | `/pricing/rates/` | Отримання поточних курсів валют (USD та EUR до UAH). Якщо на сьогодні курсів немає — система автоматично стягне їх з API ПриватБанку. | Публічний (`AllowAny`) |
| **GET** | `/pricing/rates/refresh/` | Примусове ручне оновлення курсів валют шляхом прямого запиту до API ПриватБанку та перезапису даних в БД. | Тільки Адмін (`admin`) |

### Статистика та Аналітика (Stats API)

| Метод | URL | Опис | Доступ (Permissions) |
| :--- | :--- | :--- | :--- |
| **POST** | `/stats/<car_id>/view/` | Фіксація перегляду автомобіля. Збільшує лічильники в Redis-кеші (за день, тиждень, місяць, загальний). | Публічний (`AllowAny`) |
| **GET** | `/stats/<car_id>/` | Отримання повної статистики переглядів з Redis та середніх ринкових цін на авто по регіону й країні. | Авторизований (Тільки Власник авто з `Premium` акаунтом) |

### Модерація Оголошень (Moderation API)

| Метод | URL | Опис | Доступ (Permissions) |
| :--- | :--- | :--- | :--- |
| **GET** | `/moderation/pending/` | Отримання списку всіх автомобілів, що очікують перевірки (статуси `pending` або `flagged`) | Тільки Менеджер або Адмін (`manager`, `admin`) |
| **POST** | `/moderation/cars/<car_id>/moderate/` | Запуск автоматичної перевірки опису авто на нецензурну лексику та зміна його статусу | Тільки Менеджер або Адмін (`manager`, `admin`) |
| **GET** | `/moderation/cars/<car_id>/logs/` | Перегляд повної історії логів модерації для конкретного автомобіля (сортування від нових до старих) | Тільки Менеджер або Адмін (`manager`, `admin`) |
